# Cloudflare Pages Deployment

This repository is connected to the Cloudflare Pages project `nis-sporttrack`.

- Production branch: `main`
- Build command: `npm run build`
- Build output directory: `dist`
- Required environment variables: `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY`

A successful deployment is available at https://nis-sporttrack.pages.dev.
